Control is part of the product.

Orbit asks for LinkedIn and Gmail because that is where the work happens. It opens a real browser and lets you sign in yourself.

  • ✓
    Passwords are never stored or seen.

    You sign in directly with each service. Orbit only keeps the same local browser session.

  • ✓
    Your profile and campaign history stay local.

    Your résumé, prospects, and browser sessions live on your computer rather than in a shared dashboard.

  • ✓
    You can stop at any moment.

    The managed browser remains visible while Orbit searches, evaluates profiles, and sends.

From download to first campaign in minutes.

Orbit is available for macOS 11+ and Windows 10/11. Google Chrome, LinkedIn, and Gmail are required.

  1. Install Orbit macOS

    Open the .dmg and drag Orbit into Applications.

  2. Open it once

    If macOS says the beta is damaged or cannot be opened, run this once in Terminal, then open Orbit again.

    xattr -cr "/Applications/Orbit.app"

  1. Install Orbit Windows

    Run the .exe. If Windows protects your PC, choose More info, then Run anyway; this beta is not code-signed yet.

  1. Make sure Chrome is installed

    Orbit uses a separate Chrome window so its work stays apart from everyday browsing. Get Chrome.

  2. Create your Orbit profile

    Add your background and résumé, set a networking goal, connect LinkedIn and Gmail, then start your first campaign.
